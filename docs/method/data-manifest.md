# Stream A data manifest

Run `.venv/bin/python -m pipeline.manifest --out data/manifest.json` after building the Stream A outputs (use `--data-dir` for another cache directory). It works offline, inventories the downloaded Open Targets 26.09 and STRING 12.5 files, ChEMBL 37 REST responses and UniProt mapping, and Open Targets GraphQL and dated PubChem responses; each local file gets a SHA-256 and byte count. URLs reconstructed from pinned layouts are labelled, recorded requests are preserved, and retrieval dates come from cache records, checksum-matched extraction records, or explicitly estimated file times.

Each `string_id_map.json`, `drug_targets.json`, and `disease_targets_*.json` receives a sibling `<file>.manifest.json` containing its output checksum and inferred inputs; siblings preserve the fixture contract without adding keys. Historical builds did not log which cache files they consumed, and the disease builder did not save API responses, so these limits are explicit rather than claiming exact replay; rebuilding an output requires rerunning the manifest command. The UniProt file is inventoried but unused by current producers, which map ChEMBL target components through Open Targets `proteinIds`; packet-only PubChem and API caches likewise have no dependency on these three outputs.

Provider licence pages were checked on 24 October 2026 and their URLs and terms are recorded in every entry: [Open Targets data are CC0](https://platform-docs.opentargets.org/licence), [STRING is CC BY 4.0](https://string-db.org/cgi/access?footer_active_subpage=licensing), and [ChEMBL is CC BY-SA 3.0](https://chembl.gitbook.io/chembl-interface-documentation/about). When sharing ChEMBL-derived adaptations, including in a private GitHub release, include attribution, release 37, the licence notice and share-alike terms; STRING needs attribution and a change notice. [NCBI's policy](https://www.ncbi.nlm.nih.gov/home/about/policies/) does not grant blanket rights to contributor content in PubChem, so contributor-specific redistribution permission remains unverified; do not describe all PubChem content as public domain.
