# Model jury pilot (plan §5 "Choosing the jurors")

Pilot Diseases. Keep these out of the final test:
- **v1:** rheumatoid arthritis, type 2 diabetes, Parkinson disease
- **v2:** congenital adrenal hyperplasia, biliary cirrhosis, COPD, hypertension, hyperhidrosis, low-grade glioma

- **v1:** famous true drugs. Every model scored at the ceiling, because the models recognise these drugs. This version can't separate models.
- **v2:** 2024 approvals as true drugs, with plausible decoys, run with drug names shown and hidden. With names shown, Opus, GPT-5.4 and Kimi reach Hits@5 67%. With names hidden, they score at about chance (Hits@5 33%, MRR 0.22). Most of the named advantage comes from model memory, not from the evidence packet.

Current jury: `claude-opus-5-5`, `openai-gpt-5.4`, `kimi-k3` (low reasoning effort). GLM-5.3 is to be retested once network-path evidence is in the packets.

Each folder has `summary.md` (plain-English results), `scores.json`, `panels.json` and `audit_sample.csv` (claims for manual citation checking). Generated by `jury/pilot.py` and `pipeline/panels.py`; the raw runs stay in the ignored `data/pilot/`.
