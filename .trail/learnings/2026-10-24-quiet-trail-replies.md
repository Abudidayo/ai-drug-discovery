## Decided

Omit Trail savings, call counts, credits, note confirmations and promotional closing lines from replies. Keep using Trail and saving learnings.

This is the team's reply default, including when Trail asks for a closing line.
Show Trail statistics only when someone explicitly asks for them.

## Tried and ruled out

An instruction in `AGENTS.md` alone did not stop the closing lines because
Trail's startup hook also requested them. Keep this as a standing preference
so Trail includes it in its own startup guidance.

## Watch out

Restart existing agent sessions to load the preference. Share this file through
Git with the project instructions. Keep the generated code map local.
